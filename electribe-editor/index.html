ELECTRIBE MATRIX STUDIO

—
Keine Datei geladen. Lade eine .esx/.emx (All Data von der Karte).

Felder kommen aus dem Schema. UNBESTÄTIGT = Offset geraten, VERIFIZIERT = Hardware-getestet (!).

Step-Sequenzen (128 Steps je Part, Bit0 = Step 1). Pattern wählen, Zelle klicken. Quelle: Schema (seq).

Keyboard-Noten (0–127, ≥128 = Off) und Gate-Zeiten je Step sowie Audio-In-Gates. Quelle: Schema (arr).

Offset-Discovery: before = geladene Datei, after = Datei mit genau EINEM geänderten Parameter.

Gefundene Texte sind direkt editierbar (Länge bleibt gleich, UNBESTÄTIGTE Zuordnung).

Beliebige WAV → mono, 32 kHz, 16 Bit, normalisiert. (MP3/FLAC vorher in WAV wandeln.) Sample-Audio gehört auf die Karte, nicht in SysEx.

ESX-1 Model-ID 0x71 (Korg-Doku), EMX-1 0x69 (EMiX); Requests nur für ESX-1 freigegeben. Web-MIDI braucht Chrome/Edge + MIDI-Interface; Hardware-Test steht aus.
